# B-15 — Редактор текста с подсветкой JSON и синхронизацией каретка ↔ узел

Источник правды — текст тела (research §5.3), а в v1 он только читается. Зрелого редактора кода
для Compose Desktop нет: Qawaz/compose-code-editor заброшен (2024), Jewel даёт `TextArea` без
подсветки, Monaco недоступен без WebView. Тела экранов — единицы-десятки КБ, так что задача
не в производительности, а в трёх вещах: подсветка, позиция ошибки, связь с деревом.

- **Решение: `BasicTextField(TextFieldState)` + `OutputTransformation` с собственным JSON-лексером
  (строки, числа, ключи, `type`-ключ и его значение — отдельным стилем) в `AnnotatedString`;
  ошибки синтаксиса подчёркиваются по offset'у из `SerializationException`; каретка → узел через
  карту `JsonPath → TextRange`, построенную одним проходом лексера.** Потому что новый API
  `TextFieldState` даёт стабильный offset-mapping (легаси `VisualTransformation` известен
  ошибками смещений), а карта диапазонов нужна и дереву (B-11: выбор узла → каретка), и
  диагностике (B-12: запись → строка).
- Перерисовка — по debounce 150 мс после успешного парса; при ошибке синтаксиса кадр остаётся
  прежним, а запись слоя 1 показывает где.
- Альтернатива — Highlights (KMP-движок подсветки): умеет JSON, но не даёт карту путей; лексер
  на 150 строк дешевле, чем зависимость плюс второй проход.
- Не делаем: автодополнение по схеме — v3 вместе с инспектором; форматирование —
  одна кнопка `Json { prettyPrint }`.

- AC: набор текста подсвечивается без заметной задержки на теле 100 КБ; клик по узлу в дереве
  ставит каретку на его `"type"`; клик по записи диагностики — тоже; удаление запятой даёт
  подчёркивание и запись слоя 1, кадр не пропадает.
- Якоря: `kompot-studio/.../editor/{BodyEditor,JsonLexer,PathRanges}.kt` (новые), B-11 `TreeModel`.
