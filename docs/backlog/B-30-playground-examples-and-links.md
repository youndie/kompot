# B-30 — Набор готовых тел и ссылки на витрину

Пустое поле ввода — это задание, а не витрина: посторонний закрывает страницу раньше, чем напишет
первый JSON. Нужен список готовых тел, и первое из них должно открываться сразу.

- **Решение: несколько тел на выбор, первое — сценарий деградации.** Человек, попавший на страницу
  случайно, должен увидеть главное отличие, не сделав ни одного клика.
- **Тела лежат исходниками плейграунда, а не тянутся из `kompot-client-tck/corpus/`.** Корпус —
  это пары «вход → наблюдаемый исход» для клиента, а не тела экранов (§17), и путать эти два
  корпуса ровно то, от чего спека предостерегает отдельным абзацем.
- Ссылка — из README тулкита и из README `kompot-client`; бейдж не заводим, пока страница не
  проверяется прогоном ([B-32](B-32-playground-states-under-test.md)).

- AC: страница открывается на сценарии деградации; переключение примера не теряет положение
  тумблера; ссылка из README ведёт на живую страницу.
- Якоря: `kompot-playground/src/wasmJsMain/resources/examples/*.json`, `README.md`,
  `kompot-client/README.md`.
