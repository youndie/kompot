# B-30 — Набор готовых тел и ссылки на витрину

Пустое поле ввода — это задание, а не витрина: посторонний закрывает страницу раньше, чем напишет
первый JSON. Нужен список готовых тел, и первое из них должно открываться сразу.

- **Решение: несколько тел на выбор, первое — сценарий деградации.** Человек, попавший на страницу
  случайно, должен увидеть главное отличие, не сделав ни одного клика.
- **Тела лежат исходниками плейграунда, а не тянутся из `kompot-client-tck/corpus/`.** Корпус —
  это пары «вход → наблюдаемый исход» для клиента, а не тела экранов (§17), и путать эти два
  корпуса ровно то, от чего спека предостерегает отдельным абзацем.
- Ссылка — из README тулкита и из README `kompot-client`; бейдж не заводим, пока страница не
  проверяется прогоном ([B-32](B-32-playground-states-under-test.md)).

- AC: страница открывается на сценарии деградации; переключение примера не теряет положение
  тумблера; ссылка из README ведёт на живую страницу.
- Якоря: `kompot-playground/src/wasmJsMain/resources/examples/*.json`, `README.md`,
  `kompot-client/README.md`.

## Итог

Три тела на выбор, чипами над деревом: сценарий деградации (открывается первым), форма и экран с
топиком. Это заодно закрывает то, что осталось неотмеченным в [B-26](B-26-playground-body-and-render.md):
страница теперь рисует **все три конверта** (§16.1) — голое дерево, `schema` + `screen`, и envelope
с `realtimeTopic`, — и каждый из них проверен в браузере.

Ради формы клиентам добавлен словарь форм (`form-standard` + `kompot-forms-client`) — **во всех
положениях переключателя, включая старые**. Это не мелочь: переключатель моделирует клиента, который
старше ровно на один компонент, а не такого, который знает половину протокола. Иначе форма
деградировала бы по второй причине и смазала ту единственную, о которой страница говорит.

Проверено на собранной странице: форма рисует настоящее material-поле и кнопку, дерево показывает и
половину схемы (`text_field`, `required`), и половину экрана; выбор примера **не теряет положение
переключателя** — щёлкнул «клиент выпущен раньше», сменил пример, тумблер остался. Ошибок в консоли
нет.

**Сторож над самими примерами.** Тела написаны руками, а рукописное тело протухает молча: изменится
wire-имя — страница будет показывать экран с дырой, и дыра будет выглядеть ровно тем механизмом,
который страница демонстрирует. Тест в `wasmJsTest` требует, чтобы **сегодняшний клиент не нашёл
в примерах ничего для деградации**. Проверен мутацией: испортил `text_input` на `text_inputt` —
покраснел.

Ссылка на живую страницу — в README тулкита, отдельным разделом перед спекой. В README
`kompot-client` не добавлена: такого файла нет, а заводить его ради одной ссылки — не задача этой
задачи.
