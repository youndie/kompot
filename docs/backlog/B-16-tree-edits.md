# B-16 — Правки в дереве: переставить, дублировать, удалить, сохранить

Половина правок экрана — структурные: поменять порядок карточек, убрать баннер, продублировать
строку таблицы. В тексте это вырезание блока с правильными скобками; в дереве — одно действие.
`JsonElement` неизменяем, но `JsonObject(map + (k to v))` copy-on-write по пути — три функции.

- **Решение: операции над `JsonElement` по `JsonPath` — `moveUp/moveDown`, `duplicate`
  (с новым id: `<id>-copy`, потому что дубль id ловит B-12), `delete`; результат сериализуется
  обратно в текст с `prettyPrint`, редактор получает новый текст и восстанавливает каретку по
  пути.** Потому что текст остаётся источником правды, а дерево — одним из способов его править;
  два состояния, которые надо синхронизировать, — уже одно лишнее.
- Сохранение — `Cmd+S` в источник `File`; для `Directory` — тот же файл; для `Http` — «сохранить
  как запись» в каталог фикстур потребителя. Так студия становится способом **записать** тело
  с сервера в `/recorded/*.json`, что konekt делает руками («refreshing it is deliberate work»).
- Undo/redo — стек текстов (тела маленькие), не стек операций.
- Альтернатива — редактировать `KompotComponent` и кодировать обратно: теряет неизвестные типы
  (`UnknownComponent` кодируется не тем, чем пришёл) и поля, которых нет у типа этой сборки
  (`ignoreUnknownKeys = true`).
- Не делаем: перетаскивание мышью — B-22; правку свойств — B-21.

- AC: перестановка узла меняет текст ровно в границах родительского массива и не трогает
  форматирование остального; `duplicate` даёт узел с новым id без записи в диагностике;
  `Cmd+S` при `Http` пишет файл, который открывается как `File` и рисуется тем же кадром.
- Якоря: `kompot-studio/.../edit/{JsonEdits,History,SaveAs}.kt` (новые),
  `kompot-core/.../KompotJson.kt` (`encodeKompotComponent` — почему не через объект).
