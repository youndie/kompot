# B-58 — Выпуск 0.38.0: версия, журналы, Central

Замыкающая задача этапа `release-0.38`. Последний выпуск на Central — 0.37.0. `version` в
`gradle.properties` уже поднят до 0.38.0 тем же изменением, что завело этот этап, и непрерывный канал
публикует `0.38.0.<run>`.

- **0.38.0, а не 1.0.** `UPGRADING.md` прямо говорит, что `0.x` ничего не обещает, кроме записи о
  поломке. 1.0 — обещание стабильности API и провода, и это отдельное решение, а не следствие объёма
  релиза. Если принимать его — отдельной задачей с тем, что именно обещается.
- **Почему версия поднята в начале, а не в конце.** Иначе всё, что вливается по пути, уезжало бы
  в непрерывный канал как `0.37.0.<run>` — сборкой, неотличимой по номеру от выпущенной 0.37.0, но
  несущей Compose 1.12 и новые слова провода.
- Журналы:
  - `UPGRADING.md` — Kotlin-поломки: Compose 1.12 у потребителя ([B-40](B-40-compose-line-1-12.md)),
    всё, что покажет `checkKotlinAbi`;
  - §13 SPEC — несовместимые изменения провода, если хоть одно из новых слов шло не по §15;
  - README модулей — новые типы и действия (сниппеты проверяются, [B-37](B-37-readme-snippets-are-unchecked.md)).
- **viddik — снова релиз.** С исправлением youndie/viddik#44 kompot взял snapshot `0.6.0.40` из
  Reposilite (только тесты, в опубликованное не попадает). До выпуска — следующий релиз viddik с
  Central, чтобы сборка 0.38.0 не зависела от нашего snapshot-репозитория.
- Публикация — диспатч `central.yaml` в sborka; бандл читается глазами до Publish (Central не
  переписывает версию).
- Задачи, которые к релизу не успели, снимаются с `blocked_by` явно, с причиной в этом файле, а не
  молча.
  - **B-43 снята 2026-09-25:** #51 не воспроизводится на 1.11 и 1.12, владелец закрыл issue как
    невоспроизводимый ([B-43](B-43-multiline-field-eats-the-wheel.md), «Решение»).
  - **B-62 добавлена 2026-09-25:** выделена из B-54 в стадии этого релиза; решение — соглашение
    об `id`, записанное в SPEC, и оно должно попасть в тот же выпуск, что и показ по видимости.

- AC: `io.github.youndie:kompot-bom:0.38.0` резолвится с Central; proba-бадж на ветке `badges`
  зелёный для 0.38.0; `UPGRADING.md` и §13 содержат записи этого релиза; тег `v0.38.0`.
