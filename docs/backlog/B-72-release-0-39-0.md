# B-72 — Выпуск 0.39.0

Замыкает этап `adoption-0.38`. Потребители портфеля (konekt, shashki, tacku, proba) перешли на
непрерывный канал `0.39.0.<run>` и ждали выпуска, чтобы снять с себя снапшот-репозиторий; их issue
закрываются переходом на `0.39.0` с Central.

- **0.39.0, а не 0.38.1.** С 0.38.0 есть объявленная поломка — `ScreenRoute` получил `presentation`
  (#194, binary only), и запись о ней уже в `UPGRADING.md`.
- **Провод:** `checkSchemaCompatibility -Pkompot.compat.base=v0.38.0` — одно изменение,
  `ScreenRoute.presentation` (`field-added-optional`), совместимое; в §13 писать нечего. Смена префикса
  `$id` (#202) проверкой не считается и в провод не попадает — SPEC.md §1 это уже говорит.
- **Тег до публикации:** `v0.39.0` на `4d860b8` (зелёный `main`), публикация собрана с тега —
  `central.yaml` в sborka, run 37305426126 («sources identical to v0.39.0»), deployment
  `ac046f8c-6214-4d94-8862-087f6b742478`; Publish нажал владелец.
- **Голова версии — 0.39.1** в этом же изменении: `determine-version` отказывается публиковать
  голову, у которой уже есть тег, а `0.39.0.<run>` после выпуска сортировался бы выше `0.39.0`, неся
  более новый код под видом пересборки выпуска.

- AC: `io.github.youndie.kompot:kompot-bom:0.39.0` и все координаты BOM разрешаются с Central; тег
  `v0.39.0`; голова `version` — `0.39.1`.
- Якоря: `gradle.properties`, `UPGRADING.md`, `kompot-bom/`.
