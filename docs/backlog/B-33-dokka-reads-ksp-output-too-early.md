# B-33 — Dokka читает сгенерированное KSP раньше, чем оно появляется

19.09.2026 прогон [35446138369](https://github.com/youndie/kompot/actions/runs/35446138369) на ветке
`feat/b-26-playground-body-and-render` упал на шаге публикации:

```
Execution failed for task ':kompot-images-client-coil:dokkaGeneratePublicationHtml'
> java.io.FileNotFoundException: .../kompot-images-client-coil/build/generated/ksp/metadata/
  commonMain/kotlin/io/github/youndie/kompot/generated/GeneratedImagesClientKompotRegistration.kt
```

Перезапуск **того же коммита** прошёл зелёным. Диф ветки — три файла в `kompot-playground`, к
которому dokka не подключена вовсе, и доки; `kompot-images-client-coil` ветка не трогает, а на `main`
тот же шаг зелёный. То есть это не дефект ветки, а гонка в сборке: задача dokka не объявляет
зависимости от задачи KSP, которая печатает ей исходник, и порядок решает раскладка по воркерам.

- **Чем это дороже, чем выглядит.** Флака в шаге публикации учит перезапускать красный прогон вместо
  того, чтобы его читать. Первый же настоящий дефект в этом шаге будет перезапущен в зелёное, и
  заметит его потребитель, а не CI. Один раз перезапуск здесь уже оказался правильным ответом — это и
  есть привычка, которую задача обязана убрать.
- **Решение — недостающая зависимость задач, а не отключение dokka.** Артефакт без javadoc-jar'а
  Central не принимает (#128 это уже проходил), а `dokkaGeneratePublicationHtml`, которому запретили
  видеть сгенерированное, будет документировать половину модуля и молчать об этом.
- Проверять придётся повторяемостью, а не одним прогоном: гонка, воспроизводящаяся раз в несколько
  запусков, «починена» выглядит ровно так же, как «не воспроизвелась». Прогнать `clean` + публикацию
  несколько раз подряд на пустых кэшах, прежде чем закрывать.
- Похожие пары «генератор → читатель» есть у всех модулей с KSP-реестром, а не только у этого:
  задача обязана посмотреть, кто ещё так устроен.

- AC: десять прогонов `publishToMavenLocal` на очищенном `build/` подряд — ни одного падения; причина
  названа в комментарии рядом с починкой, а не только в этом файле.
- Якоря: `kompot-images-client-coil/build.gradle.kts`, `kompot-registry-processor`,
  конвенция `io.github.youndie.sborka.publish` (применяет dokka), `.github/workflows/build.yaml`.
